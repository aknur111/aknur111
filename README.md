## Selected work

### AI Tender Platform

`LangChain` `OpenAI API` `FastAPI` `PostgreSQL` `Celery` `Redis` `WebSockets`

Parses Kazakhstan government procurement documents from `goszakup.gov.kz`, extracts requirements with an LLM, and generates tender proposals matched against a company profile. Real-time notifications over WebSockets plus a Telegram bot for subscribers.

- Semantic search over tender documents via FAISS embeddings
- Async Celery queue processing 1000+ documents per day
- Automated scoring of tender-to-company fit

### Clinic Appointment System

`Go` `Gin` `PostgreSQL` `Redis` `Docker` `JWT`

Booking platform with role-based access for patients, doctors, and admins, Redis-backed slot availability, and an email/SMS notification service.

- Clean architecture with dependency injection
- Middleware layer for auth, structured logging, and rate limiting
- Fully containerized via Docker Compose

### Vehicle Cleanliness Detection

`YOLOv8` `Python` `OpenCV` `FastAPI` `MLflow`

Fine-tuned YOLOv8 to classify vehicles as clean or dirty, served through a batch inference API for fleet analysis.

- 92%+ mAP on the evaluation set
- Full augmentation and evaluation pipeline tracked in MLflow
- Batch inference endpoint for processing fleet image sets

### E-commerce AI Assistant

`LangGraph` `OpenAI API` `FastAPI` `Redis` `WebSockets`

Multi-tool LLM agent for product search and order tracking, with persistent conversation memory in Redis, response streaming, and fallback strategies for multi-step workflows.

### Stock Signal Prediction Model

`scikit-learn` `pandas` `NumPy`

Ensemble model for buy/hold signal prediction with technical-indicator feature engineering and walk-forward backtesting.
